# Databricks Bootcamp 2026 🚀
This repository contains the practical materials, notebooks, and scripts developed during the **Databricks Bootcamp 2026**, taught by the Senior Data Engineer **Baraa Khatib Salkini** (from [Data With Baraa](https://www.datawithbaraa.com/)).

The goal of this bootcamp was to provide a hands-on, real-world perspective on how **Databricks** is utilized in enterprise environments, covering everything from SQL analytics to complex Data Engineering pipelines.

--- 

## 📚 Repository Content
Based on the bootcamp curriculum, this repository includes:

- **Medallion Architecture**: Implementing Bronze, Silver, and Gold layers.
- **Databricks SQL**: Advanced querying and dashboarding.
- **PySpark & Data Engineering**: Building robust and scalable data pipelines.
- **Delta Lake**: High-performance table management and ACID transactions.


## 🏗️ Architecture
This project follows the Medallion Architecture:

### 🥉 Bronze Layer
- Raw data ingestion
- Schema inference and storage as Delta tables

### 🥈 Silver Layer
- Data cleaning and standardization
- Type casting and validation

### 🥇 Gold Layer
- Dimensional Data Model (Business Transformation)
- Ready for BI and analysis


### 🛠️ Technologies Used
- Databricks
- Apache Spark
- PySpark
- Spark SQL
- Delta Lake
- Unity Catalog
